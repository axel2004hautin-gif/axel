# Le site d'Axel

Mon site perso, publié sur claude.ai : https://claude.ai/artifact/QcoRPH8YUBGwfVt8XqzoYY

Ouvre `index.html` dans un navigateur pour le voir en local (rien à installer).

## Les rubriques

1. **Travail** : mon boulot chez Blue Box. La garde-robe (à la racine du dépôt) y a sa place.
2. **Argent**
3. **Sport**

L'accueil présente les trois rubriques dans cet ordre, chacune avec sa couleur. Pour l'instant, chaque rubrique montre des idées de contenu, marquées « Idée » : on choisit ensemble ce qu'on garde avant de les construire.

Une adresse qui finit par `#travail`, `#argent` ou `#sport` ouvre directement la rubrique.

## Publier

`outils/version-artefact.sh site/index.html > site-axel.html`, puis publier `site-axel.html` sur la même adresse.
